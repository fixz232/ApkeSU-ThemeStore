# ApkeSU Interface Styles

This directory is generated by `scripts/generate-interface-style-store.ps1` in the ApkeSU source tree.

Each `.ksstyle` file is declarative data. It can only select a renderer and variant already shipped in the Manager APK. Packages cannot contain scripts, DEX, native libraries, or arbitrary Web content. The Manager validates the fixed GitHub URL, byte count, SHA-256, schema, engine, and variant before atomically registering a style.
